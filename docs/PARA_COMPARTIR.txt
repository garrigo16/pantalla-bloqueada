DRIFFT ANALYZER

Abre Iniciar.exe. La aplicación se instala para tu usuario y queda activa.
No necesita permisos de administrador.
El ZIP incluye el paquete completo: conserva Iniciar.exe y DrifftAnalyzer-Setup.exe juntos para instalar sin una descarga adicional.
Desde el icono junto al reloj puedes configurar pantallas, fondo, tiempos e inicio con Windows.

BROMAS
Todos los easter eggs están activos inicialmente. En Bromas y easter eggs puedes cambiar
el modo de humor o elegir Discreto. El despertar breve del fondo se puede desactivar aparte.
Hay guiños al tocar teclas, clicar y completar secuencias escondidas. Sin sonido.

ACTIVACIÓN AUTOMÁTICA
La simulación se activa inicialmente tras 300 segundos (5 minutos) sin teclado ni ratón.
El tiempo es editable y se puede desactivar desde el configurador.
No interrumpe el configurador y la salida manual espera una nueva actividad antes de volver a contar.

ACTUALIZACIONES
Se comprueban automáticamente cada 12 horas mientras la app está en ejecución.
En Configurar > Actualizaciones puedes buscar versiones y pulsar Actualizar si hay una nueva.
Si ya tienes la última, la aplicación lo indica. Descargar e instalar requiere pulsar el botón.
Las actualizaciones conservan tus ajustes y tu preferencia de inicio con Windows.
Si una copia antigua ya quedó atascada al actualizar, abre una vez el nuevo Iniciar.exe.
También puedes usar directamente DrifftAnalyzer-Setup.exe. Un fallo deja disponible el reintento y conserva la versión anterior.

Los valores iniciales son 20 segundos de fondo y un movimiento de un píxel cada 5 minutos, alternando izquierda y derecha mientras dura la simulación.
Puedes borrar este paquete tras instalarlo. Para retirar la app, usa Desinstalar.exe.

La app simula un bloqueo visual; no protege los archivos ni sustituye el bloqueo real de Windows.
Windows 10/11 con .NET Framework 4.8. Los ejecutables no tienen firma digital.

ATAJOS Y PINBALL
En Configurar > Atajos de teclado puedes elegir una combinación compartida o dos distintas.
Para el juego, añade Shift al atajo de salida (Shift queda reservado para esa función).
Ctrl izquierdo/derecho: palancas. Espacio: lanzar. P: pausa. Esc: volver a la simulación.
El atajo de salida sigue funcionando durante la partida.
